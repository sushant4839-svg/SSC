# The Marketplace Architect Handbook

A publication-ready Markdown book project for building, operating, scaling, and exiting marketplace businesses.

## Outputs

- Markdown source chapters
- Clickable SUMMARY.md table of contents
- Appendices, templates, SOPs, checklists, worksheets, case studies, resources, references, bibliography, and diagrams

## Build Targets

Use Pandoc or a publishing pipeline to generate DOCX, PDF, and printable A4 editions from these Markdown files.
